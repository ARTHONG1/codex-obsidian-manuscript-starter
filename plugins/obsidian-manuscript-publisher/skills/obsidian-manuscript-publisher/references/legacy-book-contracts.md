# Legacy Book Contracts

Load this reference only for explicit historical V1/V2 work or immutable historical packages. It is isolated from new/default V3 synthesis.

Use V1 only for explicit `기존 양식`, `레거시 양식`, or `V1`, or when opening, validating, rendering, or exporting an existing historical package without `template_version: 2`. Use V2 only for an explicit V2 request or an immutable package already marked V2. Never rewrite historical packages merely to add a field.

Historical V1 visual counts and V2 preview/preparation/Step visual contracts remain unchanged. Historical V2 preserves the fixed section order and the `step, tip, step, tip, ... step` practice-block shape, with no tip after the final Step. Historical V1/V2 rules never override a new/default request, which always routes to V3.
