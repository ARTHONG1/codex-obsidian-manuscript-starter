# v0.7.0 — 블로그와 내 양식으로 만드는 원고

기본 제공 고정 원고형을 제거했습니다. 이제 블로그를 만들거나, PDF·DOCX·이미지 예시를 분석해 승인한 사용자 양식으로 원고를 만들 수 있습니다.

- 대화별 저장·최신화·삭제, 프로젝트 등록, 초보자 설치 흐름은 유지합니다.
- 블로그는 Markdown·HTML과 바탕화면 복사용 묶음을 제공합니다.
- 사용자 양식은 후보 미리보기와 정확한 후보 ID 승인 후 사용할 수 있습니다.
- 양식을 지정하지 않은 원고 요청은 사용할 사용자 템플릿을 먼저 확인합니다.
- 기존에 만든 원고·대화·출판함 파일은 삭제하지 않습니다. 제거된 기본 양식의 새 렌더링·발행·재내보내기는 지원하지 않습니다.

처음 사용하는 분은 저장소 첫 화면의 설치 요청문을 Codex 채팅창에 붙여 넣으세요. 재시작이 필요하면 Codex가 알려 주는 문장으로 이어 갑니다.

기존 설치 사용자는 새 버전으로 업데이트해야 변경된 스킬이 적용됩니다. 이전 원고를 새 양식으로 만들려면 원하는 예시를 사용자 템플릿으로 등록한 뒤 새 버전을 요청하세요.
