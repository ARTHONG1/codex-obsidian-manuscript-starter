# v0.7.1 — 삭제와 사용자 양식 발행 안정화

기본 원고형은 다시 추가하지 않습니다. 블로그와 사용자 양식, 대화 저장 기능을 유지하면서 v0.7.0에서 안내했던 삭제·사용자 양식 문제를 수정합니다.

- 대화 삭제는 메타데이터를 마지막에 지우고 실제 남은 파일을 확인합니다. 중단된 삭제는 동일 대상과 기록을 검증한 뒤 이어갑니다.
- 사용자 양식은 승인된 스냅샷의 파일 해시를 다시 확인합니다. 잘못된 경로·변조·미승인 양식은 발행하지 않습니다.
- 사용자 양식의 이미지와 표를 Markdown·HTML·PDF에 반영합니다. 이미지 경로·크기·해시를 검사하며, 빠진 이미지를 빈 칸으로 대체하지 않습니다.
- 바탕화면 내보내기는 기존 출력 폴더를 덮어쓰지 않습니다. 파일별 해시 검증 후 완료로 표시하고, Obsidian 저장 결과와 구분합니다.

설치는 [처음 설치 안내](https://github.com/ARTHONG1/codex-obsidian-manuscript-starter#처음-설치하기)의 요청문을 Codex에 입력하세요. 기존 사용자는 새 버전으로 업데이트 후 새 작업에서 사용하세요. 기존 대화·원고·이미지는 자동 삭제하거나 변환하지 않습니다.

복잡한 원본 지면을 픽셀 단위로 복제하는 기능은 아닙니다. 사용자 양식의 미리보기를 확인하고 승인한 뒤 사용하세요. 자동 테스트 통과가 모든 사용자 PC에서 무오류를 보장하는 것은 아닙니다.
