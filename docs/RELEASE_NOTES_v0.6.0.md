# v0.6.0

`v0.6.0`은 Codex 데스크톱 초보 사용자를 위한 원스톱 옵시디언 자동화 및 배포 릴리스입니다.

## 주요 개선 사항
- **Pester & Aggregate CI 안정화**: CI 환경에서 대량 계약 테스트 실행 시 발생하던 PowerShell CLI 문자열 및 파이프라인 인자 잘림 문제를 해결하여 138개 전체 Pester 계약 및 Python 348개 테스트 수트 100% 통과를 검증했습니다.
- **초보자 1프롬프트 완결 설치**: Codex 설치만 완료된 초보 사용자가 "옵시디언 원고 환경을 처음부터 설치해줘" 단 한 문장으로 Obsidian 설치, 보관함 생성, Local REST API 연결, 플러그인 설치까지 자동 수행합니다.
- **V3 원고/블로그/커스텀 양식 지원**: A4 출판 원고, 마크다운/HTML 블로그, 사용자 커스텀 템플릿 프로필(`custom_manuscript`) 지원을 완벽하게 통합했습니다.
