# 사용 안내

## 대화 저장과 최신화

```text
이 프로젝트를 원고 프로젝트로 등록해줘.
이 대화 전체를 옵시디언 원고 재료로 저장해줘.
이 대화 원고 재료 최신화해줘.
```

현재 대화의 원본과 재료 카드를 대화 ID별로 보관합니다.

## 블로그 생성

```text
이 대화 재료로 플랫폼 독립 범용 블로그형을 만들어줘.
```

블로그형은 `blog.md`와 `blog.html`, 관련 이미지를 만듭니다. 바탕화면 출판함에서 복사할 본문과 이미지를 사용할 수 있습니다.

## 사용자 양식 등록과 원고 생성

PDF·DOCX·이미지 예시를 첨부하고 요청합니다.

```text
이 PDF를 분석해서 ‘출판사 A 원고형’ 템플릿 후보를 만들어줘.
```

미리보기를 확인한 뒤 표시된 정확한 후보 ID를 승인합니다. 최초 분석 요청만으로 등록하지 않습니다.

```text
후보 ID <표시된 ID>를 승인하고 ‘출판사 A 원고형’으로 등록해줘.
이 대화 재료로 ‘출판사 A 원고형’ 원고를 만들어줘.
```

기본 고정 원고형은 제공하지 않습니다. 원고 요청에 양식이 없으면 사용할 사용자 양식을 먼저 선택합니다. 기존 원고 파일은 보존되며 새 출력으로 자동 변환하지 않습니다.

## 결과물 사용

완료 메시지의 경로를 열면 됩니다. 블로그는 바탕화면의 `옵시디언 원고`에서 `01 본문-복사용.txt`와 이미지 삽입 순서를 확인합니다. 사용자 양식은 지정한 폴더의 Markdown·HTML·PDF를 사용합니다.

## 삭제

```text
이 대화의 옵시디언 자료 묶음만 삭제해줘.
```

현재 대화 ID의 묶음만 대상으로 하며 다른 대화는 건드리지 않습니다. 삭제 전 표시된 범위를 확인합니다.
