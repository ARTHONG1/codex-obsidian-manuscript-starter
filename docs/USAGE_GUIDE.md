# 사용 안내

## 대화 저장

```text
이 대화 전체를 옵시디언 원고 재료로 저장해줘.
```

현재 대화의 전체 원본과 정리된 재료 카드가 대화 ID별 폴더에 저장됩니다. 다른 대화 내용을 자동으로 합치지 않습니다.

## 원고 생성

```text
이 프로젝트의 지정한 대화 재료만 바탕으로 출판 원고형을 만들어줘.
```

```text
이 대화 재료로 플랫폼 독립 범용 블로그형을 만들어줘.
```

출판 원고형은 A4 HTML·PDF·Markdown을 만들고, 블로그형은 `blog.md`와 `blog.html`을 만듭니다.

## 결과물 사용

바탕화면의 `옵시디언 원고` 폴더에서 `01 본문-복사용.txt`를 복사합니다. 이미지 삽입 안내 파일을 열고 `images` 폴더의 해당 파일을 올립니다. HTML 미리보기에서 순서와 누락을 확인합니다.

## 삭제

```text
이 대화의 옵시디언 자료 묶음만 삭제해줘.
```

현재 대화 ID의 자료 폴더만 삭제하며 다른 프로젝트와 원고 버전은 삭제하지 않습니다.
